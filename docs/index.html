1. Theme Overview

Welcome to Horizon Furniture Japandi Edition, a luxury Shopify OS 2.0 theme crafted specifically for modern Furniture, Decor, and Architectural brands. Built on top of Shopify's high-performance OS 2.0 architecture, this theme is 100% redesigned with clean Scandinavian & Japandi aesthetics.

2. Installation Guide

  1. Log into your Shopify Admin panel.
  2. Navigate to Online Store → Themes.
  3. Click Add Theme → Upload zip file.
  4. Select the horizon-furniture-theme.zip file provided in your download package.
  5. Click Publish once uploaded.

3. Shopify CLI Development Setup

If you are a developer modifying theme files locally, use Shopify CLI:

# Install dependencies
npm install

# Start local dev server with hot reload
npm run dev -- --store your-store-name.myshopify.com

# Run Theme Check linter
npm run check

4. Key Furniture Features Included

Shoppable Lookbook

Dynamic hotspot pins over room staging images with product popovers.

Category Bento Grid

Architectural bento box layout for room collections.

Room Bundle Builder

Curated room set combo discount builder with 1-click add all to cart.

Before/After Slider

Interactive slider comparing timber finishes or staging transformations.

Cart Free Shipping Bar

Dynamic progress bar calculating White-Glove delivery thresholds.

Product Spec Sheet

Detailed W × D × H dimensions and FSC® material certificates on PDP.

5. Customizing Colors & Typography

Go to Theme Settings in Shopify Admin to adjust:

  • Color Tokens: Warm Cream (#FBF9F5), Soft Sand (#F3EFEA), Terracotta (#A67C52).
  • Typography: Heading font Cormorant Garamond and body font Inter.
  • Corner Radii: Default 6px for buttons/inputs, 8px for product cards.
